# PROMPT — CABEÇALHO FUTURISTA ANIMADO PARA GITHUB README

Quero que você redesenhe e implemente o cabeçalho do meu README.md do GitHub, utilizando a imagem de referência enviada como base visual.

O cabeçalho deverá manter a identidade tecnológica, com fundo escuro, tons de azul, roxo e ciano neon, mas apresentar animações modernas e elegantes.

## 1. DESIGN DO CABEÇALHO

Crie um banner horizontal com dimensões de 1200 × 360 pixels.

O design deverá conter:

* Fundo azul-marinho extremamente escuro (#080D1C).
* Gradientes suaves em azul, roxo e ciano.
* Linhas de circuitos eletrônicos distribuídas pelas laterais.
* Pequenos pontos luminosos simulando conexões digitais.
* Uma grade tecnológica muito discreta no fundo.
* Ondas luminosas atravessando a região inferior do banner.
* Tipografia moderna, tecnológica e perfeitamente centralizada.

Texto principal:

THIAGO HOLANDA

Texto secundário:

SOFTWARE DEVELOPER | COMPUTER SCIENCE

O nome deverá ser o elemento de maior destaque, utilizando branco com um brilho neon extremamente sutil.

Não utilize efeitos exagerados, fontes infantis ou elementos que prejudiquem a legibilidade.

## 2. ANIMAÇÃO DO NOME

Implemente uma animação de entrada no texto THIAGO HOLANDA.

O nome deverá surgir progressivamente, como se estivesse sendo revelado por uma interface digital futurista.

Sequência:

1. O banner inicia com o fundo escuro e os circuitos levemente iluminados.
2. Uma linha horizontal de luz percorre a região central.
3. O nome THIAGO HOLANDA aparece progressivamente da esquerda para a direita.
4. Um brilho azul e roxo percorre brevemente as letras.
5. O nome permanece completamente visível após a animação.

Duração aproximada: 3 segundos.

A animação deve ocorrer apenas uma vez, sem fazer o nome desaparecer posteriormente.

## 3. ANIMAÇÃO DOS CIRCUITOS

As linhas de circuitos deverão apresentar pequenos pulsos luminosos que percorrem seus caminhos.

Os pulsos devem simular o fluxo de dados em um circuito eletrônico.

Utilize cores como:

* Azul elétrico: #2563EB
* Ciano neon: #00D9FF
* Roxo: #7C3AED

Os pulsos devem se movimentar lentamente, sem comprometer a leitura dos textos.

A animação poderá se repetir continuamente.

## 4. ANIMAÇÃO DAS ONDAS NEON

Na parte inferior do cabeçalho, implemente três ondas luminosas.

Cada onda deverá utilizar uma cor diferente: azul, roxo e ciano.

As ondas precisam apresentar:

* Movimento horizontal suave.
* Pequenas variações de altura.
* Brilho neon discreto.
* Sobreposição com diferentes níveis de transparência.
* Movimento contínuo e fluido.

Evite movimentos rápidos ou exagerados.

O objetivo é transmitir a sensação de uma interface tecnológica viva.

## 5. ANIMAÇÃO DO SUBTÍTULO

Abaixo do nome, apresente:

SOFTWARE DEVELOPER | COMPUTER SCIENCE

Implemente uma animação de digitação, com as letras aparecendo progressivamente.

Após a digitação, o texto deverá permanecer visível.

Adicione um cursor vertical que pisque suavemente ao final do texto.

O subtítulo deve ter espaçamento uniforme entre as letras e permanecer centralizado no banner.

## 6. EFEITOS VISUAIS ADICIONAIS

Adicione pequenos detalhes que reforcem a identidade tecnológica:

* Partículas luminosas discretas.
* Pequenos pontos de luz nas conexões dos circuitos.
* Uma leve iluminação azul e roxa atrás do nome.
* Efeito de profundidade utilizando diferentes camadas.
* Pequenos detalhes geométricos inspirados em interfaces HUD.

Todos esses elementos devem ser secundários em relação ao nome.

## 7. IMPLEMENTAÇÃO NO GITHUB

O cabeçalho será utilizado exclusivamente no README.md do meu perfil do GitHub.

Portanto:

* Crie o banner como um arquivo SVG animado.
* Utilize animações SVG e CSS incorporado ao próprio SVG, compatíveis com a renderização de imagens do GitHub.
* Não utilize JavaScript, React ou bibliotecas que dependam da execução de scripts no navegador.
* Não utilize imagens externas para elementos essenciais do banner.
* Mantenha todos os elementos gráficos incorporados ao arquivo SVG.
* Garanta que o nome e o subtítulo estejam legíveis mesmo quando as animações não forem executadas.
* Respeite a preferência por movimento reduzido quando aplicável.
* O SVG deve funcionar corretamente no tema claro e escuro do GitHub.

Caso alguma animação não funcione na renderização do GitHub, implemente uma alternativa compatível utilizando SVG ou GIF otimizado.

O arquivo final deverá ter tamanho inferior a 1 MB, sempre que possível.
